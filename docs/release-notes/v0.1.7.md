# FluentQtWidgets v0.1.7

This maintenance release focuses on layout consistency, navigation behavior, display scaling, and macOS window polish.

## Highlights

- Added configurable per-row vertical alignment to `FlowLayout` and improved wrapping, spacing, and animated relayout behavior.
- Made `ScrollArea::enableTransparentBackground()` propagate to content widgets that are attached later with `setWidget()`.
- Kept navigation panels above page-transition stacks and improved navigation-tree label spacing.
- Kept the native styled navigation-stack curve and matched the exposed corner backdrop to the compact navigation surface, removing the subtle light-theme square seam.
- Aligned Gallery root-page transparency with the Python reference so page surfaces preserve the navigation stack's rounded corner.
- Centered Fluent icons by their visible bounds and preserved icon geometry at fractional display scales.
- Removed unnecessary vertical scroll bars from combo-box popup menus.
- Refined native macOS corner handling for Fluent windows.

## Examples

- The FlowLayout example now demonstrates centered alignment with mixed-height controls.
- The ScrollArea example now demonstrates configuring a transparent background before attaching its content widget.
- Gallery root pages now apply transparent scroll surfaces explicitly, matching the Python reference behavior.

## Validation

- Full CMake build and CTest suite on the supported desktop toolchain.
- Example parity verification against the maintained reference set.
- Regression coverage for FlowLayout, ScrollArea, navigation stacking, icon scaling, combo-box popup policy, and macOS window behavior.
