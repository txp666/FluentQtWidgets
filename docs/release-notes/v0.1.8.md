# FluentQtWidgets v0.1.8

This maintenance release improves realtime plot readouts, Chinese translations, and Fluent item-view behavior.

## Highlights

- Added `RealtimePlotWidget::setCrosshairXValueFormatter()` for custom X-value labels, such as formatted timestamps, and `crosshairXText()` to retrieve the formatted readout.
- Included Simplified Chinese and Traditional Chinese translations for realtime plot context menus and controls in the packaged translation resources.
- Added horizontal and vertical scroll-bar policy setters to `ListView`, `ListWidget`, `TableView`, `TableWidget`, `TreeView`, and `TreeWidget`. The setters control the Fluent scroll delegates while keeping native scroll bars hidden, with regression coverage for table and tree policies.
- Fixed macOS table selection rendering so native selection backgrounds no longer obscure Fluent selection styling, and reserved space to prevent the first-column selection indicator from overlapping text.
- Fixed Linux Gallery packaging to preserve shared-library symbolic links and find the bundled FluentQtWidgets library alongside the executable after extraction.

## Downloads

Gallery archives are available for Windows, macOS, and Linux. The Gallery update checker detects this release through the default GitHub Releases channel.

The Linux archive requires a compatible Qt 6 runtime on the target system.
