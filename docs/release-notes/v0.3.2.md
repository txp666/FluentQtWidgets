# FluentQtWidgets v0.3.2

- 实时曲线（`RealtimePlotWidget`）可以隐藏右侧的最新值标签：`setValueTagsVisible(false)`，曲线占用空出来的宽度。
- 实时曲线的刻度按 1、2、5 的整数步长排列；数据没有负值时，纵轴不再画到零以下。
- 详见 [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md)。

## English

- `RealtimePlotWidget` can hide the latest-value tags at its right edge with `setValueTagsVisible(false)`, giving their margin to the plot.
- Plot ticks step by 1, 2 or 5, and data that never goes below zero no longer gets a negative axis.
- See the [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md).
