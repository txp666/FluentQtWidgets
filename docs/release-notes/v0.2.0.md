# FluentQtWidgets v0.2.0

逐个组件对照 PyQt-Fluent-Widgets 1.11.3，修正尺寸、外观和行为。

- 按钮、输入框、日期时间、对话框、菜单、导航、视图、设置卡片和窗口与 Python 版一致。
- 新增多媒体组件（需 Qt Multimedia）：播放条、音量按钮和 `VideoWidget`。
- 修复无边框对话框按钮行被截断，下拉菜单打开时不再闪烁或偏移。
- 新 Logo，README 分中英文两版。
- 含不兼容的 API 变更，升级前请看 [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md)。

## English

Every widget checked against PyQt-Fluent-Widgets 1.11.3, with sizes, looks and behaviour fixed to match.

- Buttons, inputs, date and time, dialogs, menus, navigation, views, setting cards and windows match the Python original.
- New media widgets (with Qt Multimedia): play bars, the volume button and `VideoWidget`.
- The frameless dialog no longer cuts off its buttons, and drop-down menus open without flashing or shifting.
- A new logo, and the README in Chinese and English.
- Contains breaking API changes; see the [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md) before upgrading.
