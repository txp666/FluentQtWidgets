# FluentQtWidgets v0.3.1

- 修复 Qt 6.12.0 上数字框、日期框、时间框看不到数值的问题（Qt 的 QTBUG-151308，Qt 6.12.1 已修复）。
- 隐藏数字框的按钮（`setSymbolVisible(false)` 或只读）后，文字可以用上按钮原来的位置。
- 详见 [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md)。

## English

- Spin boxes, date edits and time edits show their values on Qt 6.12.0, which hid them (Qt's QTBUG-151308, fixed in Qt 6.12.1).
- Hiding a spin box's buttons (`setSymbolVisible(false)`, or read-only) gives the text their room.
- See the [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md).
