# FluentQtWidgets v0.1.10

This release fixes crashes from widgets that used objects after they were deleted, a long list of behaviour bugs found in a review of the whole library, and a stack overflow under Qt 6.8 on Windows. The tests now run in Windows CI.

## Highlights

- Crash fixes: info bars, navigation panel items, pop-up stacks, info badges, teaching tips, submenus, the window splash screen and line edit completers no longer use objects that have been deleted. `FlyoutView(QWidget *)` no longer crashes on `show()`, and `FluentWindow` constructs under the `offscreen` and `minimal` platform plugins on macOS.
- Qt 6.8 on Windows: the Windows 11 style sets dynamic properties on a widget while it polishes it, and each one made the style sheet manager repolish the widget again until the stack overflowed. Any widget with Fluent style sheets could crash as soon as the application set a dynamic property on it.
- Windows windows: native hit testing uses device-independent coordinates at every scale factor, also for messages without a window handle, and a maximized frameless window's client area covers the work area.
- Combo boxes: model combos follow their model's resets and row removals, show the first item of a model set with `setModel()` and no longer take ownership of the caller's model; `clear()` and `setCurrentIndex(-1)` bring the placeholder back.
- Inputs, scrolling, dialogs, menus, navigation, style sheets and charts: see the changelog for the full list. Sliders can be dragged again, progress bars and rings honour `minimum()`, scroll bar maths no longer overflows on large views, text wrapping never cuts an emoji, and the focus underline of multiline editors stays at the bottom while scrolling.

## Additions

- `themedIcon(lightPath, darkPath)`: an icon that paints the file for the current theme.
- `AcrylicBrush::setScreenCaptureEnabled()`, `isScreenCaptureEnabled()` and `isScreenCaptureAvailable()`. Acrylic surfaces capture the screen only when that has no side effects (never prompting for the Screen Recording permission on macOS) and fall back to an opaque tint.
- `RoundMenu::execAndWait()`, which returns the triggered action like `QMenu::exec()`, and `RealtimePlotWidget::setXAxisValueFormatter()`.

## Behaviour changes

- `OpacityAniStackedWidget` applies its opacity effect only while a transition runs.
- The compact spin box flyout is no longer a popup and no longer grabs the keyboard.
- `AcrylicBrush::isAvailable()` reports whether a screen capture is available instead of always returning `true`.
- Plot exports start in an existing folder (the user's download folder by default) instead of creating `app/download`.

## Tests

The tests are grouped into one suite per Gallery area and start from the same theme, accent colour and configuration. The Windows CI job builds everything and runs them, including the native hit tests at 150% scaling.

## Downloads

Gallery archives are available for Windows, macOS, and Linux. The Gallery update checker detects this release through the default GitHub Releases channel.

The Linux archive requires a compatible Qt 6 runtime on the target system.
