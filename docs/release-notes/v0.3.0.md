# FluentQtWidgets v0.3.0

- 需要 Qt 6.12。Qt 装在 Qt 安装器或 aqtinstall 的默认位置（`~/Qt`、`C:\Qt`）时，CMake 会自动找到，无需设置 `CMAKE_PREFIX_PATH`。
- Windows 11 上 `MSFluentWindow` 正常显示云母效果；在 Qt 6.10 及以上版本中，无边框窗口的云母不再一直显示为灰色。
- 切换主题时，普通窗口的系统标题栏和系统对话框跟随应用主题。
- 详见 [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md)。

## English

- Requires Qt 6.12. CMake finds a Qt that the Qt installer or aqtinstall put in its default folder (`~/Qt`, `C:\Qt`) by itself, without `CMAKE_PREFIX_PATH`.
- Mica shows in `MSFluentWindow` on Windows 11, and frameless windows no longer keep a grey Mica under Qt 6.10 and later.
- Native title bars and system dialogs follow the theme switch.
- See the [CHANGELOG](https://github.com/txp666/FluentQtWidgets/blob/main/CHANGELOG.md).
