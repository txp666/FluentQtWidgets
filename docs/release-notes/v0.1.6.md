# FluentQtWidgets v0.1.6

This release adds chart and waveform components to the C++ Gallery and includes macOS window/deployment fixes.

## Highlights

- Added `ChartWidget`, a Qt WebEngine-backed widget for rendering bundled Apache ECharts options.
- Added `AudioWaveformWidget`, an interactive QWidget-based audio waveform renderer with progress tracking.
- Expanded the Gallery chart page with ECharts bar, line, stacked area, mixed bar/line, donut, scatter, radar, gauge, heatmap, and waveform demos.
- Added simplified and traditional Chinese translations for the new Gallery entries.

## Fixes

- Fixed macOS Qt WebEngine helper deployment so `QtWebEngineProcess.app` can resolve bundled Qt frameworks such as `QtWebChannel.framework`.
- Fixed macOS Fluent window rounded-corner behavior so child content no longer hides native rounded corners.

## Packaging

- Version metadata is synchronized across CMake, public headers, vcpkg manifest, README files, and release documentation.
- Apache ECharts is bundled through the Qt resource system with a third-party notice.
